# DESIGN: Launch List

Source brief: docs/tds/examples/simple-service-brief.md

## Design Direction

Launch List should feel calm, operational, and founder-friendly: a launch-readiness cockpit, not a heavy project-management system.

## UX Principles

Clarity over density; fast first value; status visibility; low-friction collaboration; usable mobile web.

## Visual System

- Background: warm neutral or light gray.
- Surface: white cards with subtle borders.
- Primary action: focused blue or green.
- Blocker: accessible amber/red with text and icon.
- Completed: green plus text label, never color-only.
- Typography: simple sans-serif with readable numerals.
- Shape: modest rounded corners.

## Core Components

Readiness Summary Card, Blocked Task Card, Task Row, Status Badge, Area Group Header, Invite Form, Empty State.

## Interaction States

Loading skeletons, empty prompts, inline save success, recoverable errors, validation for blocked-without-note.

## Accessibility

Status indicators require text labels. Keyboard users can filter tasks, open detail, change status, and save. Contrast must be readable. Field errors should be connected to inputs.

## Responsive Behavior

Dashboard cards stack on mobile. Task filters collapse or stack. Task Detail should be full page or bottom sheet on mobile, not a cramped modal.

## Copy Tone

Direct and practical: "Blocked tasks", "Ready tasks", "Add first launch task", "Invite collaborator".
