## Navigation Model

Primary navigation: Dashboard, Task List, Settings. Task Detail opens from blocked-task cards or task rows.

## Pages / Screens

### Dashboard

Shows Launch name, target date, readiness summary, blocked task list, upcoming work, and add-task action. States: empty, loading, error, success.

### Task List

Grouped list of Tasks by Launch Area with filters for status, area, and assignee. States: empty filtered result, no launch areas, loading, error.

### Task Detail

Shows task title, description, status, blocker note, due date, area, assignee, and optional activity placeholder. Blocked status requires blocker note before save.

### Settings

Manages collaborators and Launch Areas. Founder can invite collaborator by email. Collaborator sees permission-limited state.

## User Flows

### Create a launch plan

1. Founder creates a Launch with name and target date.
2. System creates default Launch Areas.
3. Founder adds Tasks to each Launch Area.
4. System shows readiness on Dashboard.

### Mark a task as blocked

1. Founder opens Task Detail.
2. Founder changes status to blocked.
3. Founder writes blocker note.
4. System saves and highlights task on Dashboard.

### Invite a collaborator

1. Founder opens Settings.
2. Founder invites collaborator by email.
3. System sends invitation and grants access after acceptance/account creation.

## Page Data Needs

Dashboard needs Launch, readiness summary, blocked Tasks. Task List needs Launch Areas, Tasks, Users. Task Detail needs Task, areas, assignable Users, permissions. Settings needs collaborators, invitations, Launch Areas, permissions.
