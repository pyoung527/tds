## API Style

Resource/action specification only. Endpoint names are illustrative and can later map to REST, RPC, server actions, or GraphQL.

## Auth Model

Founder manages launches, tasks, launch areas, and collaborators. Collaborator views launches and updates assigned tasks. Launch plans are private by default.

## Resources and Actions

### Launches

- GET /launches: list visible launches.
- POST /launches: create launch with name and target date.
- GET /launches/{launchId}: fetch launch summary and readiness metrics.
- PATCH /launches/{launchId}: update name, target date, or status.

### Launch Areas

- GET /launches/{launchId}/areas: list launch areas.
- POST /launches/{launchId}/areas: create area.
- PATCH /areas/{areaId}: update name, description, or sort order.
- DELETE /areas/{areaId}: delete only if no tasks depend on it, or require reassignment.

### Tasks

- GET /launches/{launchId}/tasks: list tasks, filterable by status, launch area, and assignee.
- POST /launches/{launchId}/tasks: create task.
- GET /tasks/{taskId}: fetch detail.
- PATCH /tasks/{taskId}: update fields/status/blocker/assignee.
- DELETE /tasks/{taskId}: delete task.

Validation: title required; status is pending/completed/blocked; blocker_note required when blocked; area and assignee must belong to same Launch context.

### Readiness

- GET /launches/{launchId}/readiness: returns completedCount, pendingCount, blockedCount, readinessPercent, and blockedTasks.

### Collaborators

- GET /launches/{launchId}/collaborators: list collaborators.
- POST /launches/{launchId}/collaborators/invitations: invite by email.
- DELETE /launches/{launchId}/collaborators/{userId}: remove access.

## Error Cases

400 validation, 401 unauthenticated, 403 forbidden, 404 not found/not visible, 409 conflict for relationship-dependent deletes.

## Open API Decisions

Collaborator account vs invite link, single vs multiple launches, and task activity history support.
